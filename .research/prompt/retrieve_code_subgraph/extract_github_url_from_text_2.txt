The core methodology is an LLM-driven objective discovery pipeline. An LLM (GPT-4) is iteratively prompted to propose and implement new preference optimization loss functions in Python code. The process starts with an initial context of established loss functions and their performance. Each proposed function undergoes unit tests, is used to finetune a Language Model, and its performance (measured by MT-Bench scores) is fed back to the LLM. This iterative refinement allows the LLM to explore variations and novel formulations. The underlying preference optimization problem is cast as an offline supervised learning task, minimizing E(yw,yl,x)∼D [f (βρ)], where ρ is the log ratio difference of policy and reference model likelihoods, and f is the discovered scalar loss function.
